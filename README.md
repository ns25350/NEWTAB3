# NewTab

iPadOSのホーム画面の余白と配置思想を研究して作成した、オリジナルの新しいタブです。HTML・CSS・JavaScriptのみで動作し、ビルドは不要です。

## GitHub Pagesで公開

1. ZIPを展開し、**中身をすべて**GitHubリポジトリのルートへ追加します。`index.html`と`assets`フォルダが同じ階層になるようにします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source: Deploy from a branch**、**Branch: main**、**/(root)** を選び、Saveを押します。
4. Pagesに表示される公開URLを開きます。

npm、APIキー、サーバーの準備は不要です。相対パスなので `https://ユーザー名.github.io/リポジトリ名/` でも動作する構成です。

[GitHub公式：公開元の設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Chromeの「新しいタブ」に設定

GitHub Pagesへの公開だけではChromeの新しいタブは置き換わりません。拡張機能として使う場合は、同じ展開フォルダを次の手順で読み込みます。

1. Chromeで `chrome://extensions` を開きます。
2. 「デベロッパーモード」をONにします。
3. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` があるフォルダを選びます。
4. 新しいタブを開きます。

Manifest V3です。リモートのJavaScriptは使用していません。現在地用の権限を宣言していますが、位置情報の取得は「現在地を使う」を押した場合だけ行います。

[Chrome公式：新しいタブの置き換え](https://developer.chrome.com/docs/extensions/develop/ui/override-chrome-pages)

## 操作

- **検索**：検索欄、または `/` キー。`g 猫`、`yt 音楽`、`map 金沢` のような短縮コマンドに対応します。
- **ページ**：左右スワイプ、ページドット、タッチパッドの横スクロール、Shift＋ホイール。最大6ページです。
- **配置変更**：「編集」→ 上のグリップをドラッグ。右下のハンドルでサイズ変更します。重なりは赤いプレビューと文字で示し、確定しません。
- **別ページへ移動**：編集中、画面の端へ運んで少し待ちます。最後のページの右端では、上限未満なら新しいページを作ります。
- **フォルダ**：編集時にショートカットを別のショートカットへ重ねます。開いて「並べ替え・編集」から順序変更・取り出しができます。
- **キーボードで配置**：各アイテムの編集ボタンから「位置とサイズ」で列・行・幅・高さ・ページを指定できます。フォルダ内はグリップにフォーカスして矢印キーでも並べ替えられます。
- **元に戻す**：上部のボタン、またはダイアログの外で Ctrl / Command＋Z。
- **天気の詳細**：天気をタップすると、時間ごとと5日間の予報を表示します。
- **設定を閉じる**：右上の×、パネルの外側、Esc。

## ウィジェット

時計はアナログ／デジタルと12／24時間表示に対応します。時間割はクラス、今日／明日、自動切り替え時刻、45分／50分／自由設定を変更できます。自由設定は時刻の逆転や授業同士の重複を検証します。時間割の対象日は端末の日時に従います。

天気の初期地域は金沢市です。設定から地名検索または現在地へ変更できます。天気は約30分キャッシュし、キャッシュは地域の座標ごとに分けます。通信失敗時は保存データであることを表示します。天気コードや時間はOpen-MeteoのUnix秒とUTCオフセットを使用します。

イラスト検索は初期OFFです。pixiv・X・Google画像の公式検索へ移動し、作品画像のスクレイピングや転載は行いません。Google画像ではセーフ検索をONにし、各サービスの表示・年齢制限に従います。

## 保存と通信

- 配置、検索設定、時間割設定などはこのブラウザのlocalStorageに保存します。
- 壁紙はIndexedDBへ保存します。外部に送信しません。20MB以下のJPEG／PNG／WebPを読み込み、長辺2560px以下へ縮小して保存します。
- 通常の検索履歴は初期OFF。ONにした場合だけ端末内に記録します。
- Google Suggestへ検索文字、Googleのファビコン取得へ登録サイトのホスト名、Open-Meteoへ地域の座標を送信します。
- 時間割は仕様に対応するFirebaseのデータを読み取ります。クラス・曜日に登録がない場合は未登録と表示し、サンプル授業を実データとして表示しません。
- JSON書き出しは壁紙画像を含みません。公開ページと拡張機能、異なるドメインは別の保存領域です。
- 旧 `homeGridStateV3` / `homeGridStateV2` / `pixelHomeStateV1` のうち、既知のページ・配置形式を引き継ぎます。未知の形式や不正な値は補正します。新しいバージョンの設定ファイルは拒否します。
- 通信できなくても時計・保存したサイト・設定操作は利用できます。公開版のオフライン利用には最初のオンライン読み込みとキャッシュ完了が必要です。

## 確認済み範囲と制約

JavaScriptの構文、ローカルファイルの参照、Manifest、15項目のロジック検証を確認しました。テストはNode.jsがある場合、次で再実行できます。

```sh
node tests/core.test.cjs
```

Chromiumでの描画・設定・検索候補・配置変更・保存・ダークモード・文字サイズ200%はブラウザ回帰検証で確認しています。タッチ端末の実機操作、拡張機能の実インストール、外部APIの実接続は未検証です。

GitHub PagesではGoogle SuggestがCORSによって使えない場合があります。その場合も登録サイト・保存を許可した履歴の候補と通常の検索は利用できます。外部サービス側の停止や仕様変更により、取得機能が使えなくなることがあります。

## 制作方針

仕様書の参照リポジトリのコード・CSS・壁紙を流用せず、新規作成しました。Appleのロゴ・純正アプリアイコン・壁紙は同梱していません。表示するファビコンは各サイトの識別用です。Apple製品・公式テーマではありません。

ソースコードはMIT Licenseです。天気データは [Open-Meteo](https://open-meteo.com/) の提供条件に従います。

## Landscape edition とデザインスキル

ホームを穏やかな風景、検索を優先した配置、読みやすい情報カードへ更新しました。外観の自動調整は端末のライト／ダーク設定に追従します。写真を選択した場合は写真に基づく配色を使います。保存済みの配置・サイト・写真は引き継ぎ、新しい初期配置を強制しません。

[apple-design](.design-rules/SKILL.md) は `.design-rules` の Git submodule として導入しています。Codex は [AGENTS.md](AGENTS.md) の指示から利用します。新規クローン時は次を実行してください。

```sh
git submodule update --init .design-rules
```

ローカルでの確認：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

別ターミナルでロジックとブラウザ回帰検証を実行できます。

```sh
node tests/core.test.cjs
node tests/ui.smoke.cjs
```

ブラウザ検証には Node.js から解決できる `playwright` と Chromium が必要です。このクラウド環境には両方あります。別の環境では `CHROMIUM_PATH` に実行ファイル、必要なら `NEWTAB_TEST_URL` に起動済みのサーバーを指定できます。これらは検証用ツールであり、アプリを使うための npm 依存関係ではありません。成功・失敗の API 応答はテスト内で再現するため、外部サービスの実接続は検証しません。

デザイン上の判断、色のコントラスト、検証範囲は [DESIGN.md](DESIGN.md) に記載しています。


## 設定画面の刷新

PCの設定画面はカテゴリのサイドバーと詳細ペイン、幅700px未満ではグループ別の設定リストと戻る操作を使います。設定検索、壁紙プレビュー、カラー選択、時計のセグメント選択、ウィジェットの表示スイッチ、ショートカットの管理に対応します。設定は即時保存です。配置テンプレートの変更や削除は確認画面を経由します。

CSS・JavaScriptの参照にはリリース識別子を付けています。Service Workerは旧シェルキャッシュを削除し、アプリのファイルを再検証してから必要時のみオフラインキャッシュへフォールバックします。GitHub Pagesでは`.nojekyll`により、この静的サイトをJekyll処理なしで配信します。これらは公開サイトの反映完了を保証するものではなく、公開設定や実際のデプロイ状況は別途確認が必要です。


## Liquid Glass とドロワー

ホームのヘッダーと挨拶は表示しません。編集・元に戻す・設定はDockから操作します。外観設定の「マテリアル」で **Liquid Glass / 不透明** を選択でき、選択は保存されます。写真を設定していない場合、ガラス表示では同梱の抽象壁紙、不透明表示では風景の壁紙を使います。

設定、天気の詳細、追加・編集画面は [Cupertino Pane](https://github.com/tech-systems/panes) 1.5.4 によるドロワーです。上部のグラバーをドラッグして高さを変更し、下へスワイプして閉じられます。グラバーにフォーカスすると、上下矢印で高さ変更、Enter / Spaceで切り替え、Endで閉じる操作ができます。Escape、閉じるボタン、パネル外のクリックでも終了できます。ネイティブのdialogでフォーカスをパネル内に保ちます。

ライブラリはMITライセンスでローカルに同梱し、公開npmアーカイブのSHA-512を確認しています。アプリの実行時にCDNやnpmへの接続は不要です。詳細は [vendor/cupertino-pane/README.md](vendor/cupertino-pane/README.md) を参照してください。

ガラス表現はWebの透過・背景ぼかし・ハイライトによる近似です。OSのネイティブLiquid Glassを使うものではありません。対応ブラウザの「動きを減らす」「透明度を下げる」「コントラストを上げる」設定を優先します。


## 画面全体を使うグリッド

ホームのグリッドは画面全体の幅・高さを使います。Dockとページ切り替えはグリッドの上に浮かせ、専用の下部領域でグリッドを狭めません。画面内に収まらない配置は縦にスクロールでき、最下段もDockより上へ移動させて操作できます。保存済みの配置はそのまま引き継ぎます。
